# SAP Mobile Development Kit Sample App

Projeto de estudos práticos com SAP Mobile Development Kit (MDK), desenvolvido para explorar a construção de aplicações mobile integradas ao ecossistema SAP.

## Tecnologias

* SAP Mobile Development Kit
* SAP BTP
* OData V4
* Offline OData
* JavaScript
* SAP Mobile Services
* Cloud Foundry

## Funcionalidades

* Listagem de clientes
* Visualização dos detalhes do cliente
* Edição de dados do cliente
* Navegação entre páginas
* Atualização de entidades OData
* Inicialização de Offline OData
* Sincronização de dados
* Tratamento de erros
* Error Archive
* Logging
* Atualização da aplicação

## Estrutura do projeto

```text

Pages/         Páginas da aplicação
Rules/         Regras JavaScript

Images/        Recursos visuais
